# Bashwink v0.1.0-alpha release notes draft

This draft describes the intended limited developer alpha. Publication is blocked.

Bashwink uses the pinned OpenCode terminal UI and runtime. The planned macOS alpha
opens from the project directory, stages edits and permitted commands in a private
workload, and lets the developer review edits before they reach the host checkout.
The release must include one verified provider, resumable sessions, and tool
evidence. Confirm every promise against the exact release archive before publishing.

Existing local-mode provider and TaskContract capabilities remain in the repository.
The file-only Seatbelt work and isolated VM fixtures are engineering milestones.
Additional platforms, Docker, multi-agent features, memory, and provider orchestration
are outside this release.

For the final owner decision, the tag plan is an annotated `v0.1.0-alpha` at the
exact passing candidate commit. Prepare the GitHub draft and checksums after the
gate passes. Publishing the draft and inviting testers require owner approval.
