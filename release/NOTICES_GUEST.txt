COMPONENTS OF THE RELEASE ARCHIVE OUTSIDE THE OPENTUI LIBRARY
==============================================================================

This section lists the other third-party code in the archive. Every item is an unmodified
upstream build, pinned by SHA-256 in share/doc/inputs.lock.json and RELEASE_MANIFEST.json.
It is an inventory, not legal advice: the project owner must confirm that the notices and
source pointers below satisfy each licence before the archive is given to anyone else.

  Source:  https://github.com/anomalyco/opencode  tag v2.3.2,
           commit c0ad18b402eb2827fc1ee71c171b1177b3fc02d1
  These are NOT the upstream release binaries. They were rebuilt from that source with a
  libopentui built from OpenTUI v0.8.4 (https://github.com/anomalyco/opentui, commit
  d4a2af24ba50636da5f222367f91746a1bf89644) WITHOUT FFmpeg, so no FFmpeg code is present. The
  recipe, the differences from the upstream build and the hashes are in
  share/doc/NOFFMPEG_RUNTIME.md and share/doc/runtime-pins.json. The notices above cover the
  components that remain in libopentui; no FFmpeg obligation applies to this archive.
